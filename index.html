Input and Output — how Python talks to the outside world.
print()
Shout something on screen
built-in
Outputs values to the console. Accepts multiple arguments, and optional sep, end, and file parameters. The sep argument controls what goes between each value (default is a space).
Code
Output
print("Hello World!")
print("I have", 3, "apples", sep=" | ")
Hello World!
I have | 3 | apples
input()
Ask user to type something
built-in
Reads a line from standard input. Always returns a string — convert with int() or float() if you need a number. The optional prompt argument is displayed before input.
Code
Output
# User types: Alice
name = input("What is your name? ")
print("Hello,", name)
What is your name? Alice
Hello, Alice

map() / filter()
Transform and select
sequence
map(fn, iter) applies a function to every element. filter(fn, iter) keeps only elements where the function returns True. Chain them for powerful pipelines.
Code
Output
nums = [1, 2, 3, 4, 5, 6]

# map: square everything
squared = list(map(lambda x: x ** 2, nums))
print(squared)

# filter: keep only evens
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)

# chained: square the evens
result = list(map(lambda x: x**2, filter(lambda x: x%2==0, nums)))
print(result)
[1, 4, 9, 16, 25, 36]
[2, 4, 6]
[4, 16, 36]
sorted()
Return a sorted copy
sequence
Returns a new sorted list. Unlike list.sort(), it works on any iterable and doesn't modify the original. Use key= for custom sort logic and reverse=True for descending.
Code
Output
print(sorted([3, 1, 4, 1, 5]))

# Sort by length of word
words = ["banana", "pie", "apple", "watermelon"]
print(sorted(words, key=len, reverse=True))

# Sort dicts by value
people = [{"name": "Bob", "age": 30}, {"name": "Alice", "age": 25}]
print(sorted(people, key=lambda p: p["age"]))
[1, 1, 3, 4, 5]
['watermelon', 'banana', 'apple', 'pie']
[{'name': 'Alice', 'age': 25}, {'name': 'Bob', 'age': 30}]
any() / all()
Logical tests on collections
sequence
any() returns True if at least one item is truthy. all() returns True only if every item is truthy. Both short-circuit — they stop early when the answer is known.
Code
Output
nums = [2, 4, 6, 8, 10]
print(all(x % 2 == 0 for x in nums))  # all even?
print(any(x > 9 for x in nums))        # any > 9?

# Form validation
form = {"name": "Alice", "email": ""}
required = ["name", "email"]
missing = [f for f in required if not form.get(f)]
print("Missing:", missing if any(missing) else "None")
True
True
Missing: ['email']

getattr() / setattr() / hasattr()
Dynamic attribute access
inspect
These let you work with attributes by name as a string — essential for metaprogramming. getattr accepts a default fallback. Combined, they let you build objects dynamically from dictionaries.
Code
Output
class Config:
    pass

settings = {"debug": True, "port": 8080}
cfg = Config()
for key, val in settings.items():
    setattr(cfg, key, val)

print(hasattr(cfg, "debug"))
print(getattr(cfg, "port"))
print(getattr(cfg, "missing", "default"))
True
8080
default

OOP & Classes — building and using object-oriented Python.
super()
Call the parent class
OOP
Returns a proxy object that delegates method calls to the parent. Essential in inheritance hierarchies. Python uses the MRO (Method Resolution Order) to determine which parent is called.
Code
Output
class A:
    def greet(self): return "Hello from A"

class B(A):
    def greet(self): return super().greet() + " → B"

class C(B):
    def greet(self): return super().greet() + " → C"

print(C().greet())
Hello from A → B → C
property()
Make a method look like an attribute
OOP
Creates a managed attribute. Use as a decorator to add getter, setter, and deleter logic. Lets you add validation or computed values without changing the public API.
Code
Output
class Temperature:
    def __init__(self, celsius):
        self._c = celsius

    @property
    def fahrenheit(self):
        return self._c * 9/5 + 32

    @fahrenheit.setter
    def fahrenheit(self, f):
        self._c = (f - 32) * 5/9

t = Temperature(100)
print(t.fahrenheit)   # getter
t.fahrenheit = 32
print(t._c)           # setter converted it
212.0
0.0
classmethod() / staticmethod()
Methods that don't need self
OOP
@classmethod receives the class as first argument (cls) — good for factory methods. @staticmethod is just a plain function namespaced inside a class — no implicit first argument.
Code
Output
class Counter:
    count = 0

    @classmethod
    def increment(cls): cls.count += 1

Counter.increment()
Counter.increment()
print(Counter.count)

class MathHelper:
    @staticmethod
    def add(a, b): return a + b

print(MathHelper.add(10, 20))
2
30
Warning
eval() and exec() can execute arbitrary code. Never use them on untrusted user input in production.
eval()
Run a string as Python code
exec
Evaluates a single expression string and returns the result. Works great as a simple calculator. Can access local/global variables via optional namespace arguments.
Code
Output
result = eval("2 + 2 * 10")
print(result)

x = 5
print(eval("x * x"))    # uses local vars

# Calculator function
def calc(expr):
    try: return eval(expr)
    except: return "Error"

print(calc("100 * 3 + 50 / 2"))
22
25
325.0
exec()
Run a whole block of code from a string
exec
Executes a string of Python statements. Unlike eval(), it can run multi-line code including loops, class definitions, and function definitions. Always returns None.

""")

Woof!

🏆 Master Example
A single program that uses almost every built-in function — a complete student grade manager.
Student Grade Manager
100 functions in one program
all-in-one
Code
Output
# Student grade manager — uses every built-in
students = ["Alice", "Bob", "Charlie", "Diana", "Eve"]
scores   = [92, 78, 85, 60, 95]

# zip + dict
grade_book = dict(zip(students, scores))
print("Grade Book:", grade_book)

# map → floats, filter → passed
float_scores = list(map(float, scores))
passed = list(filter(lambda s: s >= 70, scores))
print("Passed:", passed)

# sorted + key → ranking
ranked = sorted(grade_book.items(), key=lambda x: x[1], reverse=True)
print("\nRanking:")
for i, (name, score) in enumerate(ranked, 1):
    print(f"  {i}. {name}: {score}")

# sum, min, max, round, len → stats
total   = sum(scores)
average = round(total / len(scores), 2)
print(f"\nAvg: {average}  Hi: {max(scores)}  Lo: {min(scores)}")

# any, all
print(f"Any failed: {any(s < 70 for s in scores)}")
print(f"All passed: {all(s >= 70 for s in scores)}")

# enumerate + bin + hex
print("\nReport Cards:")
for idx, (name, score) in enumerate(grade_book.items(), 1):
    grade = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 70 else "F"
    print(f"  {idx}. {name:10} → {score} {grade} hex:{hex(score)}")

# abs, pow, divmod
print(f"\nabs(-42)={abs(-42)}  pow(2,8)={pow(2,8)}  divmod(95,10)={divmod(95,10)}")

# set + frozenset
unique = set(scores + [92, 78])
frozen = frozenset(unique)
print("Unique:", unique)

# chr + ord
print(f"chr(65)={chr(65)}  ord('A')={ord('A')}")

# reversed + slice
print("Reversed:", list(reversed(students)))
print("Top 3:", sorted(scores, reverse=True)[slice(0,3)])
